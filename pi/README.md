# pi

The onboard brain on the Raspberry Pi 5 (laptop for now): controller at ~30 fps (behaviors, YOLO tracking, mecanum mixing, later mapping), perception (YOLO, openWakeWord, Whisper, Piper), and the client for the cloud mind (Qwen3.8-27B via OpenRouter) and memory keeper. Python first, ROS 2 later if it earns its place. API keys come from the environment, never from the repo.
