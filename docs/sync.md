# Keeping the page snapshot in sync

The master plan lives on the Grok Bot page **"Super bot"** (canvas id `45200f5a-d70f-476f-988f-23a206c0bfd9`), which Pip, Adam's Grok Bot build partner, owns and updates after every decision.

GitHub cannot embed that page live, so this repo keeps a markdown snapshot instead:

- [`docs/super-bot-page.md`](super-bot-page.md) is regenerated by Pip whenever the page changes, and committed with a message like `docs: sync Super bot page (YYYY-MM-DD)`.
- The header of the snapshot says when it was synced. If it looks stale, ask Pip (see "Talking to Pip" in `CLAUDE.md`).
- Do not hand-edit the snapshot. Propose changes to Pip instead, or record them in `docs/decisions.md`.
