# cad

Mechanical design in Autodesk Fusion.

- `fusion/`: Fusion design files (`.f3d`) or links to the cloud designs.
- `exports/`: STEP and STL exports for printing, cutting, and sharing.
- `scripts/`: Fusion API (Python) scripts that build or modify geometry, so designs are reproducible.
- `renders/`: screenshots and renders for review.

Design rules are in `CLAUDE.md`. Model real parts at real dimensions (JGB37 motors, 80 mm mecanum wheels, Pi 5, BTS7960, 18650 pack, C270, 1.3" TFT).
